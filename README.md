## Robotics Simulation Engineering course

The role-aligned course at `robotics-simulation-engineer/` starts with an intensive
14-day Isaac Sim application sprint, then continues into an evidence-first deep path
through robot model engineering, dynamics and contact validation, ROS 2, sensors,
sim-to-real methods, parallel performance, CI, MuJoCo, and Gazebo.

## Mirrored project pages

The CUDA kernel guide is mirrored from the private sibling checkout at
`..\cuda_kernel\docs\index.html` into `cuda_kernel\index.html` because GitHub
Pages is not enabled for private repos on the current plan.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\sync-cuda-kernel-guide.ps1
```
