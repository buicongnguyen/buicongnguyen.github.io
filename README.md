## Mirrored project pages

The CUDA kernel guide is mirrored from the private sibling checkout at
`..\cuda_kernel\docs\index.html` into `cuda_kernel\index.html` because GitHub
Pages is not enabled for private repos on the current plan.

Sync it before committing guide updates:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\sync-cuda-kernel-guide.ps1
```
