Three starting routes

Foundation · 10–14 weeks

Start at the entry gate

For learners missing Python, Git/CLI, transforms, or dynamics/control—or passing four or fewer domains. Complete readiness labs before simulator work.

Experienced · 4–6 weeks

Start at first weak objective

For engineers who pass all four core prerequisites and at least five domains, but still need robotics-simulation depth.

Sprint · 14 days

Start at Module 0

For engineers who pass every entry task and can sustain 6–8 focused hours per day.

Assessment loop

How to complete a module

1

Pre-check

Answer objective questions before reading; record confidence.

2

Learn

Read only the linked section and just-in-time references.

3

Perform

Complete the lab and make its tests pass.

4

Diagnose

Explain one planted failure using CIDER.

5

Post-check

Reach 80%; missed objectives enter the review queue.

6

Retain

Review after 1, 3, and 7 days and preserve the gate artifact.

Below 80% or gate failed: return to the exact weak objective and repeat Learn → Perform → Diagnose. Gate passed: schedule retention and advance.
