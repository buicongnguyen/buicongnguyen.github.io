Lab 01 runtime baseline verified

Clock and lifecycle

Build the smallest complete bridge and prove Play/Pause/Stop ownership.

Gate: advancing /clock with correct type and measurable delivery.
Lab 02 execute next

Joint states, TF, odometry

Map articulation data into schemas and a connected frame tree.

Gate: valid arrays, monotonic stamps, acyclic TF.
Lab 03 after Lab 02

Twist control and watchdog

Trace commands to wheels and prove stale input reaches zero.

Gate: expected motion plus bounded safe stop.

RGB/depth contract

Validate payload, frame, calibration, timestamp, rate, and bandwidth.

Gate: probe JSON and geometry/rate evidence pass.

Rosbag validation

Record the interface and repeat message analysis without Isaac publishers.

Gate: metadata and replay preserve declared contracts.

Never use topic existence as the final gate. A topic can exist while time is frozen, QoS is incompatible, frames are wrong, arrays are malformed, images are empty, or a controller is unsafe.

  • USD stages and graph screenshots
  • version/environment manifest
  • topic, type, QoS, frame, rate contract
  • joint/TF/odometry checks
  • watchdog log and stop-time measurement
  • camera probe JSON and bandwidth results
  • rosbag metadata and replay comparison
  • one failure-and-fix note per lab
