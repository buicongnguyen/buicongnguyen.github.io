Steps 1–2

Declare the contract and create a bounded run path

required: [/clock, /joint_states, /tf, /tf_static, /odom, /cmd_vel,
           /camera_1/rgb/image_raw, /camera_1/rgb/camera_info]
behaviors: [clock_monotonic, joint_arrays_valid, tf_acyclic,
            watchdog_zero_observed, image_probe_ok]
$Launcher = "C:\Users\n\source\repos\issac_sim\robotics-simulation-engineer\Start-IsaacRosJazzy.ps1"
$RunRoot = "C:\Users\n\source\repos\issac_sim\projects\ros2_pipeline\runs"
$Bag = Join-Path $RunRoot ("lab05_" + (Get-Date -Format "yyyyMMdd_HHmmss"))
New-Item -ItemType Directory -Force -Path $RunRoot | Out-Null
pwsh -NoProfile -ExecutionPolicy Bypass -File $Launcher ros2 topic list -t
Use an explicit topic list. Avoid record -a for the primary artifact; explicit scope prevents accidental collection and makes the interface reviewable.

Step 3

Record one controlled episode

pwsh -NoProfile -ExecutionPolicy Bypass -File $Launcher ros2 bag record -o $Bag /clock /joint_states /tf /tf_static /odom /cmd_vel /camera_1/rgb/image_raw /camera_1/rgb/camera_info
  1. Play at least 10 seconds.
  2. Send forward `/cmd_vel_raw` for 2 seconds.
  3. Stop the raw publisher; wait for the watchdog zero.
  4. Move through a visible scene region for camera/state variation.
  5. Optionally perform one documented pause/resume.
  6. Press Ctrl+C in the recorder and wait for metadata flush.
Recorder rule: do not force-kill it. Clean shutdown is part of the evidence contract.

Steps 4–5

Inspect metadata, then remove live publisher ownership

pwsh -NoProfile -ExecutionPolicy Bypass -File $Launcher ros2 bag info $Bag
Get-ChildItem -LiteralPath $Bag

Metadata

storage files, duration, topic types, message counts

Counts must be nonzero for required continuous streams.

Plausibility

size agrees with duration, image rate, and resolution

An unexpectedly tiny bag often means missing sensor data.

Isolation

close Isaac, command source, and watchdog; keep Zenoh

Require zero live publisher count before playback.
# After closing Isaac and other publishers:
pwsh -NoProfile -ExecutionPolicy Bypass -File $Launcher ros2 topic info /joint_states --verbose

Steps 6–7

Replay with observers ready and reuse prior gates

Replay terminal

 /camera_1/rgb/image_raw /camera_1/rgb/camera_info

Observer terminal

pwsh -NoProfile -ExecutionPolicy Bypass `
 -File $Launcher ros2 topic echo /joint_states --once
pwsh -NoProfile -ExecutionPolicy Bypass `
 -File $Launcher ros2 topic echo /odom --once

Camera probe

pwsh -NoProfile -ExecutionPolicy Bypass `
 -File $Launcher python `
 "C:\Users\n\source\repos\issac_sim\robotics-simulation-engineer\lab-assets\camera_probe.py" `
 --topic /camera_1/rgb/image_raw --timeout 15

Startup order

Start bounded observers before playback. If replay ends too quickly, inspect installed ros2 bag play --help before using loop/delay options.

Reuse the same validators
Lab 01clock appears and does not move backward in the recorded episode
Lab 02JointState structure and TF names/types persist
Lab 03fresh command and watchdog zero are recorded
Lab 04image payload/frame probe passes

Replay wall-arrival rates may differ unless playback rate and load are controlled. Message timestamp/schema/frame contracts are the primary comparison.

Portfolio evidence

Commit reports, not uncontrolled binary bulk

  • recording manifest + command
  • bag info and metadata summary
  • topic counts, types, duration, size
  • proof live publishers were stopped
  • replay state and camera probe
  • live-versus-replay contract table
Keep large bag files out of Git unless deliberately managed with an artifact store. Commit the small manifest, report, plots, and validation scripts.
