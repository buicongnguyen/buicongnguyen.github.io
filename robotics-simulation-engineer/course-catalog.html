External robotics simulation course catalog

Use these courses to fill a specific gap in the local curriculum. Do not complete every course in sequence. Select the resource mapped to your current module, produce the named artifact, and return to the local evidence gate.

Source policy

Primary documentation and university material are preferred. Pages marked current follow a maintained release or course landing page; learners must still record the exact simulator and library version used locally.

Avoid tutorial accumulation

Selection rules

1 · Diagnose

Name the missing capability

Choose one gap: scene composition, robot asset validation, ROS contracts, task design, policy learning, transfer, or simulator parity.

2 · Extract

Read for one contract

Record the API, invariant, workflow boundary, and version assumption needed by the current module.

3 · Build

Produce the mapped artifact

Do not count videos or page completion. Retain code, configuration, traces, diagrams, tests, or a comparison report.

4 · Return

Pass the local evidence gate

The external course supplements the dashboard; it does not replace the module lab, practice objective, or capstone gate.
